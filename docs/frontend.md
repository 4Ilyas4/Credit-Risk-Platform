# Streamlit-интерфейс

Запуск: `streamlit run frontend/app.py` (API_URL по умолчанию http://localhost:8000).

## Функции
- `api(method, path, **kw)` — обёртка над requests.
- `reset_state()` — очистка session_state + rerun.

## Экраны
1. Загрузка данных — CSV/Parquet, предпросмотр столбцов.
2. Авто-подготовка — бинаризация цели и нормализация скорa.
3. Сопоставление столбцов — пресеты, автоподсказки, fuzzy-поиск.
4. Параметры анализа — n_boot, seed, референс/периоды.
5. Запуск и статус — поллинг, ошибки.
6. Результат — сводка, метрики, скачивание отчёта.

## Состояние
- `session_state`: dataset, run, uploaded_hash, mapping, result.
- Сброс: кнопка «Сбросить всё» + автоматический сброс при смене файла.

## Требования к данным
- y_true: 0/1.
- y_score: вероятность [0,1].
- date/group/features: опционально.

## Валидация
- Проверка типа и диапазона до отправки.
- Понятные сообщения при неверном выборе.
