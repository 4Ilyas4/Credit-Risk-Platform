# Пакет валидации (`src/validation`)

Независимая проверка готовой кредитной модели. Исследовательский инструмент, не система одобрения кредитов.

## Быстрый старт

```python
from src.validation import run_full_validation

report = run_full_validation(
    y_true=y_true,            # 0/1, обязательно
    y_score=y_score,          # вероятность дефолта в [0, 1], обязательно
    X=features,               # необязательно: проверки данных, информативность, ошибки по признакам
    dates=dates,              # необязательно: backtesting по периодам
    groups=groups,            # необязательно: групповой bootstrap, ошибки по сегментам
    reference_data=reference, # необязательно: DataFrame со столбцом y_score и/или признаками, для PSI
)
report.save("report.html")    # основной формат; .pdf - экспорт, .json - машинный вид
```

Что не передано, то не проверяется. Список пропущенного лежит в `report.meta["skipped_checks"]` и показан в отчёте.

## Точки входа

| Функция | Что делает |
|---|---|
| `validate_dataset(df, target, date_col, id_col, features)` | структура, пропуски, дубликаты, выбросы, дисбаланс, достаточность, зрелость target |
| `assess_informativeness(X, y, dates)` | IV, Mutual Information, univariate AUC, корреляции, VIF, проверка утечки, стабильность IV по годам |
| `evaluate_predictions(y_true, y_score, ...)` | ROC-AUC, Gini, KS, PR-AUC, Brier, Log Loss, пороговые метрики, калибровка, интервалы, стабильность, ошибки |
| `run_full_validation(...)` | всё доступное в одном отчёте |

## Как читать результат

Каждый результат (`MetricResult`) содержит `value`, `explanation`, `interpretation`, `limitations` и `status`:
- `ok` - замечаний нет;
- `warning` - стоит обратить внимание, причина в `interpretation`;
- `not_computable` - метрика не определена на этих данных (например, в выборке один класс). Значение пустое, число не подставляется.

Пороги интерпретации - рабочие ориентиры, а не стандарты. Их условность указана в `limitations`.

## Чего пакет не делает

- Не восстанавливает чужую модель и не утверждает, что восстановил её.
- Не считает SHAP без доступа к модели (`model=` с методом `predict_proba`).
- Не оценивает качество на периодах без фактических исходов.
- Доверительные интервалы учитывают только случайность выборки, но не смену периода или популяции.
