# Словарь данных (Lending Club, accepted loans)

Источник: Lending Club, `accepted_2007_to_2018Q4.csv` (151 столбец, 2 260 701 строка).
Единица наблюдения: один выданный кредит (`id`). Период выдачи: 2007-06 ... 2018-12.
Скоринг выполняется на момент выдачи кредита.

## Целевая переменная

| Поле | Описание |
|---|---|
| `target` | 1 = дефолт (`Charged Off`, `Default`, `Does not meet the credit policy. Status:Charged Off`). 0 = погашен (`Fully Paid`, `Does not meet the credit policy. Status:Fully Paid`). Остальные статусы исключаются как незрелые. |

Ограничение: это итоговый исход, а не фиксированный 12-месячный горизонт. В данных нет даты дефолта.

## Признаки, доступные на момент выдачи (разрешены)

Числовые (float32): `loan_amnt`, `int_rate`, `installment`, `annual_inc`, `dti`, `delinq_2yrs`, `fico_range_low`, `fico_range_high`, `inq_last_6mths`, `open_acc`, `pub_rec`, `revol_bal`, `revol_util`, `total_acc`.

Категориальные и текстовые (хранятся как строки): `term`, `grade`, `sub_grade`, `emp_length`, `home_ownership`, `verification_status`, `purpose`, `addr_state`, `earliest_cr_line`.

## Признаки утечки (запрещены)

Появляются после выдачи и раскрывают исход.

| Поле | Одномерный AUC | Причина |
|---|---|---|
| `last_fico_range_high`, `last_fico_range_low` | 0.94 (high) | FICO на момент последней проверки, после выдачи |
| `recoveries`, `collection_recovery_fee` | 0.84 (recoveries) | Взыскание после дефолта |
| `total_pymnt`, `total_pymnt_inv`, `total_rec_prncp`, `total_rec_int`, `total_rec_late_fee` | 0.76 (total_pymnt) | Платежи зависят от исхода |
| `out_prncp`, `out_prncp_inv`, `last_pymnt_d`, `last_pymnt_amnt`, `next_pymnt_d`, `last_credit_pull_d` | 0.50 (out_prncp) | Состояние кредита после выдачи. Для `out_prncp` слабая связь, потому что у завершённых кредитов остаток равен 0. Признак всё равно запрещён по смыслу |
| `hardship_*`, `settlement_*`, `debt_settlement_flag`, `pymnt_plan` | не измерялся | Программы помощи после выдачи |
| `funded_amnt`, `funded_amnt_inv` | не измерялся | Сумма фактического финансирования, известна после решения. Требует ручной проверки |
| `loan_status` | - | Источник target |

AUC измерен только для `last_fico_range_high`, `recoveries`, `total_pymnt`, `out_prncp` и разрешённых числовых признаков. Остальное отнесено к утечке по смыслу поля.

## Служебные поля

| Поле | Описание |
|---|---|
| `id` | Идентификатор кредита, дубликатов нет. |
| `issue_d` | Дата выдачи, формат `Mon-YYYY`, преобразуется в datetime. Используется для временного разделения. |
| `loan_status` | Итоговый статус. Только для построения `target`. |

## Качество данных

- `member_id`: 100% пропусков.
- `next_pymnt_d`: 99.8% пропусков.
- `hardship_*`: около 99.6% пропусков.
- Полные дубликаты и повторы `id` после очистки: 0.
- Пропуски среди разрешённых признаков после очистки: `emp_length` 5.83%, `revol_util` 0.07%, `dti` 0.03%, остальные 0%. Строк хотя бы с одним пропуском: 5.89%.
- Дисбаланс классов: 0 к 1 примерно 4 к 1 (дефолт 19.98%).
- Дефолт по сроку: 36 месяцев 16.0% (1 023 206 кредитов), 60 месяцев 32.5% (324 893).
- Дефолт по грейду растёт монотонно: A 6.0%, B 13.4%, C 22.4%, D 30.4%, E 38.4%, F 45.1%, G 49.7%.
- Распределение `fico_range_low` меняется по годам выдачи: среднее около 715 в 2009-2011, около 693 в 2014-2015, 708 в 2018. Это уже видимый сдвиг популяции, он важен для тестов на стабильность.

## Ограничения

- Разделение полей на разрешённые и запрещённые составлено по смыслу полей и сверено с заголовком файла. Официальный словарь Lending Club построчно не сверялся.
- AUC-проверка находит только сильную одномерную утечку. Порог 0.85 пропустил `recoveries` и `total_pymnt` (см. D-005 в `decisions.md`).
- Реальные данные содержат остаточное смещение зрелости в 2017-2018 годах.
