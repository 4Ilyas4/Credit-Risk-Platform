# Credit Scoring Model Validator

Исследовательская платформа независимой проверки кредитных скоринговых моделей: качество данных, качество предсказаний, калибровка, стабильность и статистическая надёжность. Это не система одобрения кредитов.

Полное описание: `Description.txt`. Журнал решений: `docs/decisions.md`.

## Статус

- Фаза 1 (Data Foundation): начата - загрузка, target, контроль утечки (`src/data`).
- Остальные фазы: см. `Description.txt`.

## Запуск тестов

```
pip install -e .[dev]
pytest
```

## Принцип выбора инструментов

Инструмент подключается только при конкретной измеренной проблеме (см. `docs/decisions.md`).
